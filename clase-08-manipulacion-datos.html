Funciones de manipulación
y transformación de datos

En esta clase trabajamos con funciones de manipulación de datos, útiles para convertir tipos, extraer partes de un valor, formatear fechas y realizar cálculos dentro de las consultas.

Concepto general

Las funciones de manipulación de datos permiten transformar, convertir, formatear y procesar información almacenada en una base de datos. Son muy utilizadas en las consultas SELECT, así como en cláusulas como WHERE.

Las funciones de manipulación de datos son herramientas incorporadas en SQL Server que permiten procesar, transformar y adaptar la información almacenada en las bases de datos durante la ejecución de una consulta. A diferencia de las operaciones de inserción, actualización o eliminación, estas funciones no modifican los valores almacenados en las tablas: generan resultados derivados a partir de ellos.

Clasificación general

En SQL Server, las funciones de manipulación de datos suelen agruparse en diferentes categorías:

  • Funciones de texto

    Permiten trabajar con cadenas de caracteres: concatenar, convertir a mayúsculas o minúsculas, buscar, extraer fragmentos o medir su longitud.

  • Funciones numéricas

    Se utilizan para realizar cálculos matemáticos, redondeos y otras operaciones sobre valores numéricos.

  • Funciones de fecha y hora

    Facilitan el manejo de fechas, horarios, intervalos de tiempo y cálculos temporales.

  • Funciones de conversión

    Permiten transformar un dato de un tipo a otro, por ejemplo convertir un número a texto o una cadena a fecha.

Funciones de texto en SQL Server

Las funciones de texto permiten trabajar con datos de tipo carácter (CHAR, VARCHAR, NCHAR, NVARCHAR, entre otros). Son utilizadas para modificar, analizar, combinar y formatear cadenas de texto dentro de las consultas SQL.

Estas funciones resultan especialmente útiles cuando se trabaja con nombres de personas, direcciones, correos electrónicos, códigos alfanuméricos y cualquier otro dato almacenado como texto.
Función Significado Ejemplo
+ Concatena cadenas de texto cuando los tipos son compatibles. Apellido + ', ' + Nombre
CONCAT Concatena varios valores de distinto tipo sin necesidad de conversión manual. CONCAT(Apellido, ', ', Nombre)
UPPER Transforma texto a mayúsculas. UPPER(Apellido)
LOWER Transforma texto a minúsculas. LOWER(Apellido)
LEN Devuelve la longitud de una cadena. LEN(Apellido)
SUBSTRING Extrae una parte del texto: texto, posición inicial y cantidad de caracteres. SUBSTRING(Apellido, 1, 5)
CHARINDEX Devuelve la posición de un carácter o subcadena dentro de un texto. CHARINDEX('o', Apellido)
Concatenar con el operador +
SELECT Apellido + ', ' + Nombre
FROM Director;

Si intentás concatenar texto con una fecha sin convertirla, SQL Server puede devolver error. En ese caso conviene usar CAST o CONCAT.

SELECT Apellido + ',' + Nombre + ' ' + CAST(FechaNac AS VARCHAR(10))
FROM Director;
Ejemplos individuales
SELECT CONCAT(Apellido, ', ', Nombre) FROM Director;
SELECT UPPER(Apellido) FROM Director;
SELECT LOWER(Apellido) FROM Director;
SELECT LEN(Apellido), Apellido FROM Director;
SELECT SUBSTRING(Apellido, 1, 5), Apellido FROM Director;
SELECT CHARINDEX('o', Apellido), Apellido FROM Director;
Ejemplo combinado
SELECT
    Apellido,
    UPPER(Apellido) AS MAYUSCULAS,
    LOWER(Apellido) AS MINUSCULAS,
    LEN(Apellido) AS LONGITUD_CADENA,
    SUBSTRING(Apellido, 1, 5) AS CADENA_PARCIAL,
    CHARINDEX('A', Apellido) AS POSICION_PRIMERA_A
FROM Director;

Funciones de fecha y hora

Las funciones de fecha permiten extraer partes de una fecha, calcular diferencias, sumar o restar intervalos y armar formatos más legibles para el usuario.

Función Significado Ejemplo
YEAR Obtiene el año de una fecha. YEAR(FechaNac)
MONTH Obtiene el mes de una fecha. MONTH(FechaNac)
DAY Obtiene el día de una fecha. DAY(FechaNac)
DATENAME Devuelve el nombre del mes o del día de la semana. DATENAME(month, FechaNac)
DATEADD Suma o resta un intervalo a una fecha. DATEADD(year, 1, FechaNac)
DATEDIFF Calcula la diferencia entre dos fechas en años, meses o días. DATEDIFF(year, FechaNac, GETDATE())
GETDATE() Devuelve la fecha y hora actual del servidor. GETDATE()
Extracción y transformación de fechas
SELECT
    FechaNac,
    CAST(FechaNac AS DATE) AS solo_fecha,
    YEAR(FechaNac) AS anio,
    MONTH(FechaNac) AS mes,
    DAY(FechaNac) AS dia,
    DATENAME(month, FechaNac) AS nombre_mes,
    DATENAME(weekday, FechaNac) AS nombre_dia,
    DATEADD(year, 1, FechaNac) AS un_anio_mas,
    DATEDIFF(year, FechaNac, GETDATE()) AS anios_hasta_hoy,
    DATEDIFF(month, FechaNac, GETDATE()) AS meses_hasta_hoy,
    DATEDIFF(day, FechaNac, GETDATE()) AS dias_hasta_hoy,
    CONVERT(varchar, FechaNac, 106) AS Fecha_Abreviada,
    CONCAT(
        DATENAME(weekday, FechaNac), ' ',
        CAST(DAY(FechaNac) AS CHAR(2)), ' de ',
        DATENAME(month, FechaNac), ' de ',
        CAST(YEAR(FechaNac) AS CHAR(4))
    ) AS fecha_larga
FROM Director;

CAST(FechaNac AS DATE) convierte un valor DATETIME a solo fecha. CONVERT(..., 106) muestra la fecha en formato abreviado según el estilo elegido.

Calcular edad a partir de la fecha de nacimiento
-- Por diferencia de años (puede fallar si aún no cumplió años)
SELECT CONCAT(Apellido, ', ', Nombre), FechaNac,
       DATEDIFF(YEAR, FechaNac, GETDATE()) AS EDAD
FROM Director;
-- Por diferencia de días (manera más correcta)
SELECT CONCAT(Apellido, ', ', Nombre), FechaNac,
       CONVERT(INT, (DATEDIFF(day, FechaNac, GETDATE()) / 365.25)) AS EDAD
FROM Director;
DATEDIFF(YEAR, ...) cuenta años calendario completos, no siempre la edad real. Si la persona todavía no cumplió años en el año actual, el resultado puede quedar desfasado en uno.

Funciones numéricas en SQL Server

Las funciones numéricas permiten realizar operaciones matemáticas y transformaciones sobre datos de tipo numérico. Son ampliamente utilizadas para efectuar cálculos, redondeos y análisis de información dentro de las consultas SQL.

En SQL es posible realizar cálculos entre columnas numéricas con cualquier operador aritmético: +, -, * y /.
Función / operador Significado Ejemplo
+ - * / Operadores aritméticos para calcular entre columnas o valores. Recaudacion - Presupuesto
% Devuelve el resto de una división. 10 % 4 devuelve 2
ABS() Obtiene el valor absoluto de un número. ABS(-123)
ROUND() Redondea un número a una cantidad de decimales indicada. ROUND(1.327532, 2)
PI() Devuelve el valor de π. ROUND(PI(), 2)
Cálculos entre columnas
SELECT *, Recaudacion - Presupuesto
FROM Pelicula;

Así podés obtener la diferencia entre recaudación y presupuesto para cada película.

Operador módulo y ejemplos numéricos
SELECT 10 % 5;   -- retorna 0
SELECT 10 % 4;   -- retorna 2

SELECT ABS(-123);

SELECT 134.25 / 7;
SELECT ROUND(1.327532, 2);
SELECT ROUND(PI(), 2);
SELECT ROUND(1.265853, 2);

Funciones de conversión

CAST, CONVERT y FORMAT permiten transformar un valor de un tipo de dato a otro o mostrarlo con un formato más legible.

Función Significado Ejemplo
CAST Convierte un valor a otro tipo de dato. CAST(FechaNac AS DATE)
CONVERT Convierte un valor y permite indicar un estilo de formato. CONVERT(varchar, FechaNac, 106)
FORMAT Formatea un número o fecha según una máscara. FORMAT(1234567, 'N0')
Conversiones de tipo
SELECT CAST(FechaNac AS DATE) FROM Director;
SELECT CONVERT(INT, 25.65);
SELECT CONVERT(varchar, FechaNac, 106) FROM Director;
SELECT CONVERT(varchar, FechaEstreno, 106) FROM Pelicula;
SELECT FORMAT(1234567, 'N0');

El estilo 106 en CONVERT muestra la fecha como dd mon yyyy, por ejemplo 15 Jan 2024.

CAST y CONVERT cumplen funciones similares. La diferencia principal es que CONVERT permite elegir un estilo de formato al convertir fechas o números a texto.

Resumen de funciones

Esta tabla resume las funciones principales de la clase para que te quede como machete visual rápido al practicar en SQL Server.

Categoría Funciones clave Uso principal
Texto CONCAT, UPPER, LOWER, LEN, SUBSTRING, CHARINDEX Combinar, transformar y analizar cadenas.
Fecha y hora YEAR, MONTH, DAY, DATENAME, DATEADD, DATEDIFF Extraer partes, calcular diferencias y sumar intervalos.
Numéricas ABS, ROUND, %, operadores aritméticos Calcular, redondear y obtener restos de división.
Conversión CAST, CONVERT, FORMAT Cambiar tipos de dato y mostrar valores con formato.
Recordá que estas funciones no modifican la tabla: solo transforman el resultado de la consulta. Si necesitás guardar el valor transformado, deberás usar UPDATE o una vista.
