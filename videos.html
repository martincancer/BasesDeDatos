Uso sugerido

Estos videos no reemplazan la clase ni el material escrito, pero ayudan mucho para repasar. Se pueden usar para revisar un tema puntual, seguir una práctica otra vez o recuperar una explicación paso a paso.

  • Conviene verlos junto con la clase HTML correspondiente.
  • Son útiles para frenar, volver atrás y repetir una parte puntual.
  • Funcionan bien como apoyo antes de practicar en SQL Server.
