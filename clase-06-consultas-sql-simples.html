Consultas SQL Simples
sobre una sola tabla

En esta clase trabajamos con consultas SELECT sobre una única tabla. El foco está en recuperar datos, elegir columnas, filtrar filas, buscar por patrones, ordenar resultados y limitar cuántas filas devuelve SQL Server.

SELECT y sintaxis general

La instrucción SELECT es el comando principal para consultar datos. Aunque trabajemos sobre una sola tabla, la consulta tiene un orden de cláusulas que conviene respetar siempre para evitar errores de sintaxis.

En SQL Server el orden general es estricto: SELECT → FROM → WHERE → ORDER BY. Si alterás ese orden, la consulta no funciona.
Sintaxis general
SELECT [TOP n] columnas | *
FROM tabla
[WHERE condicion]
[ORDER BY columna ASC | DESC];
Formas básicas de seleccionar datos

Todas las columnas

SELECT *
FROM Pelicula;

Es práctico para explorar, pero en consultas reales conviene pedir solo lo necesario.

Columnas específicas

SELECT PeliculaID, TituloOriginal, FechaEstreno
FROM Pelicula;

El orden en que listás las columnas es el mismo en el que aparecen en el resultado.

Resultado parcial
PeliculaID TituloOriginal FechaEstreno Presupuesto
1 Jurassic Park 1993-06-11 63000000.00
2 Spider-Man 2002-05-03 140000000.00
3 King Kong 2005-12-14 207000000.00
4 Superman Returns 2006-07-14 204000000.00
Usar * es útil para practicar, pero listar columnas hace la consulta más clara, evita traer datos innecesarios, y no es recomendable en producción, debido a la sobrecarga de datos.
Alias de columnas
SELECT
  TituloOriginal AS 'Titulo Original',
  FechaEstreno AS 'Fecha de Estreno',
  Presupuesto AS Costo
FROM Pelicula;

Si el alias no tiene espacios, las comillas son opcionales. Con espacios, conviene usar comillas o corchetes.

WHERE: filtrar filas

La cláusula WHERE sirve para decidir qué filas se incluyen en el resultado. Cada fila se evalúa contra la condición y solo se muestran las que la cumplen.

Si una condición da verdadero, la fila aparece. Si da falso o NULL, la fila queda afuera del resultado.
Operador Significado Ejemplo
= Igual a TituloOriginal = 'Spider-Man'
<> o != Distinto de TituloOriginal <> 'Spider-Man'
>, >= Mayor / mayor o igual Presupuesto >= 1000000
<, <= Menor / menor o igual Presupuesto < 500000
Ejemplo con WHERE
SELECT PeliculaID, TituloOriginal, FechaEstreno, Presupuesto
FROM Pelicula
WHERE Presupuesto < 1000000;
La potencia de SELECT aparece de verdad cuando lo combinás con filtros. Ahí dejás de ver "todo" y empezás a buscar justo lo que necesitás.

Operadores de búsqueda

Además de comparar valores, una consulta simple puede combinar condiciones, buscar rangos, encontrar patrones de texto y detectar nulos.

AND y OR

AND

SELECT *
FROM Pelicula
WHERE Presupuesto < 100000
  AND FechaEstreno > '19900101';

Ambas condiciones deben ser verdaderas.

OR

SELECT *
FROM Pelicula
WHERE Presupuesto < 100000
   OR FechaEstreno > '19900101';

Al menos una condición debe cumplirse.

Cuando mezclás AND y OR, usá paréntesis. AND tiene mayor precedencia que OR, y eso puede cambiar el resultado si no lo controlás.
BETWEEN, LIKE e IS NULL
  • 1
    BETWEEN 
    SELECT *
FROM Pelicula
WHERE Presupuesto BETWEEN 100000 AND 500000;

    Incluye ambos extremos del rango.

  • 2
    LIKE 
    SELECT *
FROM Pelicula
WHERE TituloOriginal LIKE '%ROBOT%';

    El porcentaje % funciona como comodín para cualquier secuencia de caracteres.

  • 3
    IS NULL 
    SELECT *
FROM Pelicula
WHERE Presupuesto IS NULL;

    Para comprobar nulos se usa IS NULL o IS NOT NULL, no = NULL.

ORDER BY: ordenar resultados

ORDER BY define en qué orden aparecen las filas del resultado. Si no lo usás, SQL Server no garantiza ningún orden particular.

ASC ordena de menor a mayor y es el valor por defecto. DESC ordena de mayor a menor.
Ordenación simple
SELECT TituloOriginal, FechaEstreno, Presupuesto
FROM Pelicula
ORDER BY FechaEstreno DESC;

En este caso, las películas más nuevas aparecen primero.

Resultado parcial ordenado
TituloOriginal FechaEstreno Presupuesto
Passengers 2016-12-21 110000000.00
Rogue One: A Star Wars Story 2016-12-10 200000000.00
Silence 2016-11-29 50000000.00
Underworld: Blood Wars 2016-11-24 NULL
Más de un criterio
SELECT TituloOriginal, FechaEstreno, Presupuesto
FROM Pelicula
ORDER BY FechaEstreno DESC, TituloOriginal ASC;

SQL Server ordena de izquierda a derecha: primero por fecha y, si hay empate, por título.

En SQL Server, los valores NULL aparecen primero en orden ascendente y al final en orden descendente.

TOP: limitar filas devueltas

TOP permite limitar la cantidad de filas que devuelve una consulta. Es muy útil cuando querés ver solo una parte del resultado, como los 5 registros más recientes o los 10 más costosos.

Ejemplo con TOP
SELECT TOP 5 TituloOriginal, FechaEstreno, Recaudacion
FROM Pelicula
ORDER BY Recaudacion DESC;

Así obtenés las 5 películas con mayor recaudación.

Si usás TOP sin ORDER BY, las filas devueltas pueden ser arbitrarias. Para que el resultado tenga sentido, conviene acompañarlo siempre con un criterio de orden.
Ejemplo de salida con TOP
TituloOriginal FechaEstreno Recaudacion
Avatar 2009-12-18 2923706026.00
Avengers: Endgame 2019-04-26 2799439100.00
Titanic 1997-12-19 2264743305.00
Star Wars: The Force Awakens 2015-12-18 2071310218.00
Avengers: Infinity War 2018-04-27 2052415039.00
