Funciones de agrupación
y resumen de datos

En esta clase trabajamos con funciones de agrupación para obtener totales, cantidades, promedios, máximos y mínimos, y aprendemos a combinarlas con GROUP BY y HAVING.

Concepto general

Las funciones de agrupación en SQL permiten efectuar operaciones sobre un conjunto de resultados, devolviendo un único valor agregado para todos ellos. Es decir, nos permiten obtener totales, cantidades, medias, máximos, mínimos, etc., sobre un conjunto de valores.

A diferencia de las funciones de manipulación de datos, que transforman fila por fila, las funciones de agrupación resumen muchas filas en un solo resultado. Cuando queremos ese resumen por categorías (por género, por país, por director), entra en juego la cláusula GROUP BY.

Funciones básicas

Los gestores de bases de datos relacionales suelen soportar estas funciones de agrupación:

Función Descripción
COUNT Devuelve la cantidad de filas o valores no nulos.
MIN Devuelve el valor mínimo de una columna.
MAX Devuelve el valor máximo de una columna.
SUM Suma los valores de una columna numérica.
AVG Devuelve el promedio de una columna numérica.
Estas funciones se aplican sobre columnas específicas entre paréntesis, excepto COUNT, que también puede usarse con * para contar filas.

Funciones de agrupación

Cada función responde a una pregunta distinta sobre los datos. Todas se usan dentro del SELECT y, en muchos casos, conviene darles un alias con AS.

Función Significado Ejemplo
COUNT(*) Cuenta la cantidad total de filas del resultado. COUNT(*) FROM Pelicula
COUNT(columna) Cuenta valores no nulos de una columna. COUNT(Presupuesto)
MIN() Obtiene el valor mínimo. MIN(Presupuesto)
MAX() Obtiene el valor máximo. MAX(Recaudacion)
SUM() Suma valores numéricos. SUM(Recaudacion)
AVG() Calcula el promedio de valores numéricos. AVG(Presupuesto)
Ejemplos individuales
-- Cantidad de películas en la tabla
SELECT COUNT(*) FROM Pelicula;

-- Presupuesto más bajo
SELECT MIN(Presupuesto) FROM Pelicula;

-- Recaudación más alta
SELECT MAX(Recaudacion) FROM Pelicula;

-- Suma total de recaudaciones
SELECT SUM(Recaudacion) FROM Pelicula;

-- Promedio de presupuesto
SELECT AVG(Presupuesto) FROM Pelicula;
Consulta con todas las funciones
SELECT
    COUNT(Presupuesto) AS Cant_Sin_Presupuesto_Nulo,
    COUNT(PeliculaID) AS Cant_Total,
    MAX(Presupuesto) AS Maximo,
    MIN(Presupuesto) AS Minimo,
    AVG(Presupuesto) AS Promedio,
    SUM(Recaudacion) AS Valor_Total
FROM Pelicula;

COUNT(Presupuesto) no cuenta filas donde el presupuesto es NULL. COUNT(PeliculaID) cuenta todas las películas con identificador.

COUNT(*)

Cuenta todas las filas devueltas por la consulta, sin importar si alguna columna tiene NULL.

COUNT(columna)

Cuenta solo los valores no nulos de esa columna. Si hay NULL, esos registros no se incluyen en el conteo.

SUM y AVG solo se pueden utilizar en columnas numéricas. Si la columna tiene valores nulos, esos registros no participan del cálculo.

Agrupando resultados con GROUP BY

La cláusula GROUP BY permite agrupar filas según las columnas que se indiquen. Se suele utilizar junto con funciones de agrupación para obtener datos resumidos por categoría.

Cuando usás GROUP BY, SQL Server devuelve un resultado por cada combinación distinta de valores en las columnas indicadas. Si en el SELECT hay funciones de agrupación y también columnas sin agregar, esas columnas deben aparecer en el GROUP BY.
Cantidad de películas por género (por ID)
SELECT COUNT(*) AS Cantidad,
       GeneroID
FROM Pelicula
GROUP BY GeneroID;

Agrupa por el identificador del género. Cada fila del resultado representa un grupo distinto.

Cantidad de películas por nombre de género
SELECT COUNT(p.PeliculaID) AS Cantidad,
       g.Genero
FROM Pelicula p
INNER JOIN Genero g ON p.GeneroID = g.GeneroID
GROUP BY g.Genero;

Acá se combina un INNER JOIN con GROUP BY para mostrar el nombre del género en lugar del ID.

Resumen completo por género
SELECT MAX(p.Presupuesto) AS Maximo,
       MIN(p.Presupuesto) AS Minimo,
       AVG(p.Presupuesto) AS Promedio,
       SUM(p.Recaudacion) AS Total_Recaudacion,
       COUNT(p.PeliculaID) AS Cantidad,
       g.Genero
FROM Pelicula p
INNER JOIN Genero g ON g.GeneroID = p.GeneroID
GROUP BY g.Genero;

Con una sola consulta podés ver el máximo, mínimo, promedio, suma y cantidad de películas de cada género.

Si hay más de una columna sin agregar, todas deben listarse en GROUP BY, separadas por coma.

Cláusula HAVING

La cláusula HAVING se utiliza junto con GROUP BY para filtrar grupos que cumplen ciertas condiciones de agrupación. Es similar a WHERE, pero actúa sobre el resultado ya agrupado.

WHERE

Filtra filas antes de agrupar. No puede usar funciones de agrupación directamente.

HAVING

Filtra grupos después de agrupar. Permite condiciones sobre COUNT, SUM, AVG, etc.

Filtrar grupos por suma de recaudación
SELECT SUM(p.Recaudacion) AS Total,
       g.Genero
FROM Pelicula p
INNER JOIN Genero g ON p.GeneroID = g.GeneroID
GROUP BY g.Genero
HAVING SUM(p.Recaudacion) > 0
   AND SUM(p.Recaudacion) < 5000000000;

Solo se muestran los géneros cuya suma de recaudación está dentro del rango indicado.

Otro ejemplo: géneros con más de 5 películas
SELECT g.Genero,
       COUNT(p.PeliculaID) AS Cantidad
FROM Pelicula p
INNER JOIN Genero g ON p.GeneroID = g.GeneroID
GROUP BY g.Genero
HAVING COUNT(p.PeliculaID) > 5;
No podés escribir WHERE SUM(Recaudacion) > 1000. Las condiciones sobre funciones de agrupación van en HAVING, no en WHERE.

Resumen de la clase

Esta tabla resume las piezas principales para consultas con agregaciones. Conviene tenerla a mano al practicar en SQL Server.

Elemento Uso principal Ejemplo corto
COUNT Contar filas o valores no nulos COUNT(*) FROM Pelicula
MIN / MAX Obtener el valor mínimo o máximo MAX(Recaudacion)
SUM / AVG Sumar o promediar columnas numéricas AVG(Presupuesto)
GROUP BY Agrupar resultados por una o más columnas GROUP BY GeneroID
HAVING Filtrar grupos según agregaciones HAVING COUNT(*) > 5
Orden mental útil: primero definís qué querés resumir, después por qué columna agrupar y, si hace falta, qué grupos filtrar con HAVING.
