Funciones definidas
por el usuario

En esta clase trabajamos con funciones escalares definidas por el usuario: rutinas reutilizables que reciben parámetros, encapsulan una lógica y devuelven un único valor.

Concepto general

Las funciones definidas por el usuario, o UDF (User-Defined Functions), permiten encapsular una lógica de negocio en un objeto reutilizable dentro de SQL Server.

En esta clase veremos funciones escalares: reciben cero o más parámetros, realizan una operación y devuelven un único valor. Ese valor puede utilizarse dentro de una consulta como si fuera el resultado de una columna.
01

Reutilizar lógica

Una regla o cálculo se define una sola vez y se invoca cuando sea necesario.

02

Recibir parámetros

Los datos de entrada permiten que la función responda a cada caso concreto.

03

Devolver un valor

Una función escalar retorna un solo resultado, con el tipo indicado en RETURNS.

04

Mejorar lectura

Las consultas quedan más claras al reemplazar cálculos repetidos por un nombre expresivo.

Las UDF se guardan dentro de la base de datos. Por eso pueden ser utilizadas por otras consultas y por otros usuarios que trabajen sobre esa misma base.

Sintaxis de una función escalar

Para crear una función se utiliza CREATE FUNCTION. Después se indican sus parámetros, el tipo de valor que devolverá y la lógica necesaria para obtener ese resultado.

Estructura general
CREATE FUNCTION nombreFuncion (
    @parametro1 AS TipoDeDato,
    @parametro2 AS TipoDeDato
)
RETURNS TipoDeDato
AS
BEGIN
    -- instrucciones
    RETURN valor
END;
PartePara qué sirve
CREATE FUNCTIONInicia la creación de la función y le asigna un nombre.
ParámetrosReciben los datos de entrada que necesita la lógica.
RETURNSIndica el tipo de dato del único resultado que devolverá la función.
AS BEGIN ... ENDDelimita las instrucciones que se ejecutarán.
RETURNEntrega el valor final calculado.
El tipo indicado en RETURNS debe ser compatible con el valor enviado en RETURN.

Ejemplo: total de ventas de un cliente

La siguiente función recibe el identificador de un cliente y devuelve la suma de los importes de todas sus ventas.

Función uf_SumaVentas
CREATE FUNCTION uf_SumaVentas(@clienteid AS INT)
RETURNS NUMERIC(18,2)
AS
BEGIN
    DECLARE @total AS NUMERIC(18,2);

    SELECT @total = SUM(Importe)
    FROM Ventas
    WHERE ClienteId = @clienteid;

    RETURN @total;
END;

La variable @total guarda el resultado de SUM(Importe); al finalizar, ese mismo valor es retornado por la función.

1Entrada: la función recibe @clienteid.
2Cálculo: busca las ventas de ese cliente y suma sus importes.
3Salida: devuelve el total obtenido en @total.

Llamar y utilizar una función

Para invocar una función se escribe su propietario, normalmente dbo, seguido del nombre y los valores de sus parámetros entre paréntesis.

Llamada directa
SELECT dbo.uf_SumaVentas(799);

El valor 799 se pasa como argumento para el parámetro @clienteid.

Usarla como una columna dentro de una consulta
SELECT
    RazonSocial,
    NroDoc,
    Direccion,
    dbo.uf_SumaVentas(ClienteId) AS ResultadoFuncion
FROM Clientes;

La función se evalúa para cada cliente y agrega una columna con su total de ventas.

Consulta directa

Devuelve un resultado puntual para un valor específico.

Dentro de SELECT

Permite incluir el resultado como parte de cada fila de una consulta.

¿Dónde se encuentran?

Las funciones definidas por el usuario quedan almacenadas dentro de la base de datos. En SQL Server Management Studio se pueden localizar desde el Explorador de objetos.

Ruta en SQL Server Management Studio
Base de datos
└── Programmability / Programación
    └── Functions / Funciones
        └── Scalar-valued Functions / Funciones escalares

Al hacer clic derecho sobre una función y elegir Modificar, SQL Server abre su definición en el editor para poder revisarla o cambiarla.

Usar un prefijo como uf_ ayuda a reconocer rápidamente que un objeto es una función creada por el usuario.
